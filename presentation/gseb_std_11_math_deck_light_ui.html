High-Yield Formula Bank & Trigonometric Identities (ત્રિકોણમિતિય નિત્યસમો)

GSEB Board Cheat Sheet

Sum-to-Product (C-D સૂત્રો)

sin C + sin D = 2 sin[(C+D)/2] cos[(C-D)/2]
sin C - sin D = 2 cos[(C+D)/2] sin[(C-D)/2]
cos C + cos D = 2 cos[(C+D)/2] cos[(C-D)/2]
cos C - cos D = -2 sin[(C+D)/2] sin[(C-D)/2]

*Beware: cos C - cos D has a negative sign!

Half-Angle Formulas (અડધા ખૂણા)

cos 2x = 2 cos²x - 1 = 1 - 2 sin²x
sin²(x/2) = [ 1 - cos x ] / 2
cos²(x/2) = [ 1 + cos x ] / 2
tan(x/2) = sin(x/2) / cos(x/2)

Problem 1 • സ്വാધ્યાય 3 Q2

Prove the Identity (સાબિત કરો):

(sin 3x + sin x) sin x + (cos 3x - cos x) cos x = 0

Official GSEB Step Marking [3 Marks]

1. Expand & regroup terms correctly +1.0 Mark
2. Apply cos(A-B) & cos 2x identity +1.0 Mark
3. Simplify to cos 2x - cos 2x = 0 +1.0 Mark

99%er Clinical Note:

Expand brackets first, then group cos 3x cos x + sin 3x sin x to instantly match the classic cos(A - B) expansion!

SMARTBOARD WORKSPACE
LHS Expression Expansion:

LHS = sin 3x · sin x + sin² x + cos 3x · cos x - cos² x

Step 1: Group cos 3x cos x and sin 3x sin x together

= (cos 3x · cos x + sin 3x · sin x) - (cos² x - sin² x)

Step 2: Apply cos(A - B) = cos A cos B + sin A sin B and cos 2x = cos² x - sin² x

= cos(3x - x) - cos 2x = cos 2x - cos 2x

Result: = 0 = RHS (જે સાબિત થાય છે - Q.E.D.)
Problem 2 • સ્વાધ્યાય 3 Q3

Prove the Sum of Squares Identity:

(cos x + cos y)² + (sin x - sin y)² = 4 cos²[(x+y)/2]

Official GSEB Step Marking [4 Marks]

1. Apply cos C + cos D formula +1.0 Mark
2. Apply sin C - sin D formula +1.0 Mark
3. Factor out common 4 cos²((x+y)/2) +1.0 Mark
4. Apply cos²θ + sin²θ = 1 identity +1.0 Mark

99%er Surgical Strategy:

Apply C-D sum-to-product formulas inside the brackets before squaring. This reveals a common factor of 4 cos²((x+y)/2)!

SMARTBOARD WORKSPACE
Step 1: Substitute C-D formulas inside both squared terms

LHS = [ 2 cos((x+y)/2) cos((x-y)/2) ]² + [ 2 cos((x+y)/2) sin((x-y)/2) ]²

Step 2: Factor out common term 4 cos²((x+y)/2)

= 4 cos²((x+y)/2) · [ cos²((x-y)/2) + sin²((x-y)/2) ]

Step 3: Simplify inside bracket using cos²θ + sin²θ = 1

= 4 cos²((x+y)/2) · [ 1 ]

Final Answer: = 4 cos²[(x+y)/2] = RHS (સાબિત થાય છે)
Problem 3 • સ્વાધ્યાય 3 Q4

Prove Difference of Squares:

(cos x - cos y)² + (sin x - sin y)² = 4 sin²[(x-y)/2]

Official GSEB Step Marking [4 Marks]

1. Apply cos x - cos y = -2 sin sin +1.0 Mark
2. Apply sin x - sin y = 2 cos sin +1.0 Mark
3. Factor out 4 sin²((x-y)/2) +1.0 Mark
4. Simplify sin² + cos² = 1 +1.0 Mark

99%er Warning on Minus Sign:

When squaring [-2 sin((x+y)/2) sin((x-y)/2)]², the negative sign becomes positive: +4 sin² sin²!

SMARTBOARD WORKSPACE
Step 1: Apply cos C - cos D and sin C - sin D identities

LHS = [ -2 sin((x+y)/2) sin((x-y)/2) ]² + [ 2 cos((x+y)/2) sin((x-y)/2) ]²

Step 2: Factor out common term 4 sin²((x-y)/2)

= 4 sin²((x-y)/2) · [ sin²((x+y)/2) + cos²((x+y)/2) ]

Step 3: Simplify bracket to 1

= 4 sin²((x-y)/2) · [ 1 ]

Final Result: = 4 sin²[(x-y)/2] = RHS (જે સાબિત થાય છે)
Problem 4 • સ્વાધ્યાય 3 Q5

4-Term Sine Series Proof:

sin x + sin 3x + sin 5x + sin 7x = 4 cos x cos 2x sin 4x

Official GSEB Step Marking [4 Marks]

1. Group pairs: (sin 7x + sin x) & (sin 5x + sin 3x) +1.0 Mark
2. Apply sin C + sin D to both pairs +1.0 Mark
3. Factor out common 2 sin 4x +1.0 Mark
4. Apply cos C + cos D to inner bracket +1.0 Mark

99%er Angle Pairing Trick:

Calculate average angles: (7+1)/2 = 4 and (5+3)/2 = 4. Grouping these creates common factor sin 4x instantly!

SMARTBOARD WORKSPACE
Step 1: Group extreme and inner pairs

LHS = (sin 7x + sin x) + (sin 5x + sin 3x)

Step 2: Apply sin C + sin D = 2 sin((C+D)/2) cos((C-D)/2)

= 2 sin 4x cos 3x + 2 sin 4x cos x

Step 3: Factor out 2 sin 4x and apply cos 3x + cos x = 2 cos 2x cos x

= 2 sin 4x [ cos 3x + cos x ] = 2 sin 4x [ 2 cos 2x cos x ]

Final Answer: = 4 cos x cos 2x sin 4x = RHS (સાબિત થાય છે)
Problem 5 • સ્વાધ્યાય 3 Q9

Half-Angle Values Evaluation:

Given cos x = -1/3 where x is in Quadrant III (તૃતીય ચરણ), calculate sin(x/2), cos(x/2), tan(x/2).

π < x < 3π/2 (Quadrant III)

Official GSEB Step Marking [4 Marks]

1. State quadrant range for x/2 (π/2 < x/2 < 3π/4) +1.0 Mark
2. Calculate sin(x/2) with positive sign +1.0 Mark
3. Calculate cos(x/2) with negative sign +1.0 Mark
4. Calculate tan(x/2) = sin(x/2)/cos(x/2) +1.0 Mark

99%er Quadrant Diagnostic:

Divide interval by 2: π/2 < x/2 < 3π/4 (Quadrant II). In Quad II: sin(x/2) > 0, cos(x/2) < 0, tan(x/2) < 0.

SMARTBOARD WORKSPACE
Step 1: Compute sin(x/2) = +√[ (1-cos x)/2 ]

sin(x/2) = +√[ (1 - (-1/3))/2 ] = √[ (4/3)/2 ] = √(2/3) = √6 / 3

Step 2: Compute cos(x/2) = -√[ (1+cos x)/2 ] (Minus sign due to Quad II)

cos(x/2) = -√[ (1 + (-1/3))/2 ] = -√[ (2/3)/2 ] = -1/√3 = -√3 / 3

Step 3: Compute tan(x/2) = sin(x/2) / cos(x/2)

tan(x/2) = (√6 / 3) / (-√3 / 3) = -√2

Final Values: sin(x/2) = √6/3 , cos(x/2) = -√3/3 , tan(x/2) = -√2
Problem 6 • સ્વાધ્યાય 3 Q10

Given sin x = 1/4 in Quadrant II:

Find sin(x/2), cos(x/2), tan(x/2) where π/2 < x < π.

cos x = -√(1 - sin²x) = -√(1 - 1/16) = -√15 / 4

Official GSEB Step Marking [4 Marks]

1. Find cos x = -√15/4 (Quad II) +1.0 Mark
2. Determine x/2 range (π/4 < x/2 < π/2) Quad I +1.0 Mark
3. Calculate sin(x/2) & cos(x/2) (both positive) +1.0 Mark
4. Calculate tan(x/2) ratio +1.0 Mark

99%er Range Check:

Since π/2 < x < π ➔ π/4 < x/2 < π/2 (Quadrant I). All values (sin, cos, tan) are POSITIVE!

SMARTBOARD WORKSPACE
Step 1: Calculate sin(x/2) = √[ (1 - cos x)/2 ]

sin(x/2) = √[ (1 - (-√15/4))/2 ] = √[ (4 + √15)/8 ] = √[ (8 + 2√15)/16 ] = (√5 + √3)/4

Step 2: Calculate cos(x/2) = √[ (1 + cos x)/2 ]

cos(x/2) = √[ (1 + (-√15/4))/2 ] = √[ (4 - √15)/8 ] = √[ (8 - 2√15)/16 ] = (√5 - √3)/4

Step 3: Calculate tan(x/2) = sin(x/2)/cos(x/2)

tan(x/2) = (√5 + √3) / (√5 - √3) = 4 + √15

Final Values: sin(x/2)=(√5+√3)/4 , cos(x/2)=(√5-√3)/4 , tan(x/2)=4+√15
