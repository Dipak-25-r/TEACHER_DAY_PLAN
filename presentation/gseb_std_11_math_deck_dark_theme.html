Sum-to-Product (C-D Formulas)

$$\sin C + \sin D = 2 \sin\frac{C+D}{2} \cos\frac{C-D}{2}$$
$$\sin C - \sin D = 2 \cos\frac{C+D}{2} \sin\frac{C-D}{2}$$
$$\cos C + \cos D = 2 \cos\frac{C+D}{2} \cos\frac{C-D}{2}$$
$$\cos C - \cos D = -2 \sin\frac{C+D}{2} \sin\frac{C-D}{2}$$

Product-to-Sum Formulas

$$2 \sin A \cos B = \sin(A+B) + \sin(A-B)$$
$$2 \cos A \sin B = \sin(A+B) - \sin(A-B)$$
$$2 \cos A \cos B = \cos(A+B) + \cos(A-B)$$
$$2 \sin A \sin B = \cos(A-B) - \cos(A+B)$$

Half-Angle & Double-Angle Identities

$$\sin^2\frac{x}{2} = \frac{1 - \cos x}{2}$$
$$\cos^2\frac{x}{2} = \frac{1 + \cos x}{2}$$
$$\tan\frac{x}{2} = \frac{\sin(x/2)}{\cos(x/2)}$$

Problem 1 • સ્વાધ્યાય 3 Q1

Prove Identity (સાબિત કરો):

$$2 \cos \frac{\pi}{13} \cos \frac{9\pi}{13} + \cos \frac{3\pi}{13} + \cos \frac{5\pi}{13} = 0$$

GSEB Marking Scheme [3 Marks]

1. Apply $2 \cos A \cos B = \cos(A+B) + \cos(A-B)$ +1.0 Mark
2. Apply supplementary angle rule $\cos(\pi - \theta) = -\cos\theta$ +1.0 Mark
3. Cancel terms to get $0$ +1.0 Mark

Teacher Explanation:

Use product-to-sum identity $2\cos A \cos B = \cos(A+B) + \cos(A-B)$ on the first term!

SMARTBOARD SOLUTION WORKSPACE
Step 1: Apply Product-to-Sum formula $2\cos A \cos B$

$$\text{LHS} = \cos\left(\frac{9\pi}{13} + \frac{\pi}{13}\right) + \cos\left(\frac{9\pi}{13} - \frac{\pi}{13}\right) + \cos\frac{3\pi}{13} + \cos\frac{5\pi}{13}$$

Step 2: Simplify angles

$$= \cos\frac{10\pi}{13} + \cos\frac{8\pi}{13} + \cos\frac{3\pi}{13} + \cos\frac{5\pi}{13}$$

Step 3: Convert using $\cos(\pi - \theta) = -\cos\theta$

$$= \cos\left(\pi - \frac{3\pi}{13}\right) + \cos\left(\pi - \frac{5\pi}{13}\right) + \cos\frac{3\pi}{13} + \cos\frac{5\pi}{13} = -\cos\frac{3\pi}{13} - \cos\frac{5\pi}{13} + \cos\frac{3\pi}{13} + \cos\frac{5\pi}{13} = 0$$

Result: $= 0 = \text{RHS}$ (સાબિત થાય છે - Q.E.D.)
Problem 2 • સ્વાધ્યાય 3 Q2

Prove Identity (સાબિત કરો):

$$(\sin 3x + \sin x)\sin x + (\cos 3x - \cos x)\cos x = 0$$

GSEB Marking Scheme [3 Marks]

1. Expand brackets & re-group terms +1.0 Mark
2. Apply $\cos(A-B)$ & $\cos 2x$ identity +1.0 Mark
3. Simplify to $\cos 2x - \cos 2x = 0$ +1.0 Mark

Teacher Explanation:

Expand brackets first, then group $\cos 3x \cos x + \sin 3x \sin x$ to apply $\cos(A - B) = \cos(3x - x) = \cos 2x$ directly!

SMARTBOARD SOLUTION WORKSPACE
LHS Expression Expansion:

$$\text{LHS} = \sin 3x \cdot \sin x + \sin^2 x + \cos 3x \cdot \cos x - \cos^2 x$$

Step 1: Group cosine and sine product terms together

$$= (\cos 3x \cdot \cos x + \sin 3x \cdot \sin x) - (\cos^2 x - \sin^2 x)$$

Step 2: Apply $\cos(A - B)$ & $\cos 2x = \cos^2 x - \sin^2 x$

$$= \cos(3x - x) - \cos 2x = \cos 2x - \cos 2x = 0$$

Result: $= 0 = \text{RHS}$ (જે સાબિત થાય છે - Q.E.D.)
Problem 3 • સ્વાધ્યાય 3 Q3

Sum of Squares Identity:

$$(\cos x + \cos y)^2 + (\sin x - \sin y)^2 = 4 \cos^2\frac{x+y}{2}$$

GSEB Marking Scheme [4 Marks]

1. Apply $\cos C + \cos D$ formula +1.0 Mark
2. Apply $\sin C - \sin D$ formula +1.0 Mark
3. Factor out $4 \cos^2\frac{x+y}{2}$ +1.0 Mark
4. Simplify bracket using $\cos^2\theta + \sin^2\theta = 1$ +1.0 Mark

Classroom Key Concept:

Apply sum-to-product C-D formulas inside the brackets before squaring!

SMARTBOARD SOLUTION WORKSPACE
Step 1: Substitute C-D formulas inside squared terms

$$\text{LHS} = \left[ 2 \cos\frac{x+y}{2} \cos\frac{x-y}{2} \right]^2 + \left[ 2 \cos\frac{x+y}{2} \sin\frac{x-y}{2} \right]^2$$

Step 2: Factor out common term $4 \cos^2\frac{x+y}{2}$

$$= 4 \cos^2\frac{x+y}{2} \cdot \left[ \cos^2\frac{x-y}{2} + \sin^2\frac{x-y}{2} \right]$$

Step 3: Simplify inner bracket using $\cos^2\theta + \sin^2\theta = 1$

$$= 4 \cos^2\frac{x+y}{2} \cdot [1]$$

Final Answer: $= 4 \cos^2\frac{x+y}{2} = \text{RHS}$ (જે સાબિત થાય છે)
Problem 4 • સ્વાધ્યાય 3 Q4

Difference of Squares Proof:

$$(\cos x - \cos y)^2 + (\sin x - \sin y)^2 = 4 \sin^2\frac{x-y}{2}$$

GSEB Marking Scheme [4 Marks]

1. Apply $\cos x - \cos y = -2\sin\sin$ +1.0 Mark
2. Apply $\sin x - \sin y = 2\cos\sin$ +1.0 Mark
3. Factor out $4 \sin^2\frac{x-y}{2}$ +1.0 Mark
4. Simplify $\sin^2 + \cos^2 = 1$ +1.0 Mark

Common Student Pitfall:

When squaring $\left[-2 \sin\frac{x+y}{2} \sin\frac{x-y}{2}\right]^2$, the negative sign turns into positive $+4$!

SMARTBOARD SOLUTION WORKSPACE
Step 1: Apply C-D formulas

$$\text{LHS} = \left[ -2 \sin\frac{x+y}{2} \sin\frac{x-y}{2} \right]^2 + \left[ 2 \cos\frac{x+y}{2} \sin\frac{x-y}{2} \right]^2$$

Step 2: Factor out common term $4 \sin^2\frac{x-y}{2}$

$$= 4 \sin^2\frac{x-y}{2} \cdot \left[ \sin^2\frac{x+y}{2} + \cos^2\frac{x+y}{2} \right]$$

Step 3: Simplify bracket to 1

$$= 4 \sin^2\frac{x-y}{2} \cdot [1]$$

Final Result: $= 4 \sin^2\frac{x-y}{2} = \text{RHS}$ (સાબિત થાય છે)
Problem 5 • સ્વાધ્યાય 3 Q5

4-Term Series Proof:

$$\sin x + \sin 3x + \sin 5x + \sin 7x = 4 \cos x \cos 2x \sin 4x$$

GSEB Marking Scheme [4 Marks]

1. Pair terms: $(7x, x)$ and $(5x, 3x)$ +1.0 Mark
2. Apply $\sin C + \sin D$ formula to both +1.0 Mark
3. Factor out common $2\sin 4x$ +1.0 Mark
4. Apply $\cos C + \cos D$ to inner terms +1.0 Mark

Pairing Hack:

Average angles: $\frac{7+1}{2} = 4$ and $\frac{5+3}{2} = 4$. This guarantees $\sin 4x$ as a common factor!

SMARTBOARD SOLUTION WORKSPACE
Step 1: Group extreme and inner terms

$$\text{LHS} = (\sin 7x + \sin x) + (\sin 5x + \sin 3x)$$

Step 2: Apply $\sin C + \sin D = 2 \sin\frac{C+D}{2} \cos\frac{C-D}{2}$

$$= 2 \sin 4x \cos 3x + 2 \sin 4x \cos x$$

Step 3: Factor out $2 \sin 4x$ & apply $\cos 3x + \cos x = 2 \cos 2x \cos x$

$$= 2 \sin 4x [\cos 3x + \cos x] = 2 \sin 4x [2 \cos 2x \cos x]$$

Final Answer: $= 4 \cos x \cos 2x \sin 4x = \text{RHS}$ (સાબિત થાય છે)
Problem 6 • સ્વાધ્યાય 3 Q6

Fraction Identity Proof:

$$\frac{(\sin 7x + \sin 5x) + (\sin 9x + \sin 3x)}{(\cos 7x + \cos 5x) + (\cos 9x + \cos 3x)} = \tan 6x$$

GSEB Marking Scheme [4 Marks]

1. Apply $\sin C + \sin D$ to numerator terms +1.0 Mark
2. Apply $\cos C + \cos D$ to denominator terms +1.0 Mark
3. Factor out common $2\sin 6x$ and $2\cos 6x$ +1.0 Mark
4. Simplify to $\frac{\sin 6x}{\cos 6x} = \tan 6x$ +1.0 Mark

Key Solving Tip:

Notice how both pairs in numerator produce $\sin 6x$ and denominator pairs produce $\cos 6x$!

SMARTBOARD SOLUTION WORKSPACE
Step 1: Apply C-D sum formulas to Numerator & Denominator

$$\text{LHS} = \frac{2 \sin 6x \cos x + 2 \sin 6x \cos 3x}{2 \cos 6x \cos x + 2 \cos 6x \cos 3x}$$

Step 2: Factor out $2\sin 6x$ in numerator and $2\cos 6x$ in denominator

$$= \frac{2 \sin 6x \cdot (\cos x + \cos 3x)}{2 \cos 6x \cdot (\cos x + \cos 3x)}$$

Step 3: Cancel common factor $(\cos x + \cos 3x)$

$$= \frac{\sin 6x}{\cos 6x} = \tan 6x$$

Final Answer: $= \tan 6x = \text{RHS}$ (સાબિત થાય છે)
Problem 7 • સ્વાધ્યાય 3 Q7

Triple Angle Identity Proof:

$$\sin 3x + \sin 2x - \sin x = 4 \sin x \cos\frac{x}{2} \cos\frac{3x}{2}$$

GSEB Marking Scheme [4 Marks]

1. Group $(\sin 3x - \sin x) + \sin 2x$ +1.0 Mark
2. Apply $\sin 3x - \sin x = 2\cos 2x \sin x$ +1.0 Mark
3. Factor out $2\sin x$ & apply $\cos 2x + \cos x$ +1.0 Mark
4. Simplify to $4 \sin x \cos\frac{x}{2} \cos\frac{3x}{2}$ +1.0 Mark

Pairing Strategy:

Group $\sin 3x - \sin x$ together first! This yields $2\cos 2x \sin x$, which pairs perfectly with $\sin 2x = 2\sin x \cos x$.

SMARTBOARD SOLUTION WORKSPACE
Step 1: Group terms as $(\sin 3x - \sin x) + \sin 2x$

$$\text{LHS} = 2 \cos 2x \sin x + 2 \sin x \cos x$$

Step 2: Factor out $2 \sin x$

$$= 2 \sin x (\cos 2x + \cos x)$$

Step 3: Apply $\cos C + \cos D = 2 \cos\frac{C+D}{2} \cos\frac{C-D}{2}$

$$= 2 \sin x \left[ 2 \cos\frac{3x}{2} \cos\frac{x}{2} \right] = 4 \sin x \cos\frac{x}{2} \cos\frac{3x}{2}$$

Final Answer: $= 4 \sin x \cos\frac{x}{2} \cos\frac{3x}{2} = \text{RHS}$ (સાબિત થાય છે)
Problem 8 • સ્વાધ્યાય 3 Q8

Half-Angle Evaluation:

Given $\tan x = -\frac{4}{3}$ where $x$ is in Quadrant II (દ્વિતીય ચરણ), find $\sin\frac{x}{2}, \cos\frac{x}{2}, \tan\frac{x}{2}$.

$$\sec^2 x = 1 + \tan^2 x = 1 + \frac{16}{9} = \frac{25}{9} \implies \cos x = -\frac{3}{5}$$

GSEB Marking Scheme [4 Marks]

1. Calculate $\cos x = -\frac{3}{5}$ (Quad II) +1.0 Mark
2. Determine range for $x/2$ ($\frac{\pi}{4} < x/2 < \frac{\pi}{2}$) Quad I +1.0 Mark
3. Compute $\sin(x/2) = \frac{2}{\sqrt{5}}$ & $\cos(x/2) = \frac{1}{\sqrt{5}}$ +1.0 Mark
4. Compute $\tan(x/2) = 2$ +1.0 Mark

Quadrant Check:

Since $\frac{\pi}{2} < x < \pi \implies \frac{\pi}{4} < \frac{x}{2} < \frac{\pi}{2}$ (Quadrant I). All half-angle functions are POSITIVE!

SMARTBOARD SOLUTION WORKSPACE
Step 1: Compute $\sin(x/2) = \sqrt{\frac{1-\cos x}{2}}$

$$\sin\frac{x}{2} = \sqrt{\frac{1 - (-3/5)}{2}} = \sqrt{\frac{8/5}{2}} = \sqrt{\frac{4}{5}} = \frac{2}{\sqrt{5}} = \frac{2\sqrt{5}}{5}$$

Step 2: Compute $\cos(x/2) = \sqrt{\frac{1+\cos x}{2}}$

$$\cos\frac{x}{2} = \sqrt{\frac{1 + (-3/5)}{2}} = \sqrt{\frac{2/5}{2}} = \sqrt{\frac{1}{5}} = \frac{1}{\sqrt{5}} = \frac{\sqrt{5}}{5}$$

Step 3: Compute $\tan(x/2) = \frac{\sin(x/2)}{\cos(x/2)}$

$$\tan\frac{x}{2} = \frac{2/\sqrt{5}}{1/\sqrt{5}} = 2$$

Final Values: $\sin\frac{x}{2} = \frac{2\sqrt{5}}{5}, \cos\frac{x}{2} = \frac{\sqrt{5}}{5}, \tan\frac{x}{2} = 2$
Problem 9 • સ્વાધ્યાય 3 Q9

Half-Angle Evaluation:

Given $\cos x = -\frac{1}{3}$ where $x$ lies in Quadrant III (તૃતીય ચરણ), calculate $\sin\frac{x}{2}, \cos\frac{x}{2}, \tan\frac{x}{2}$.

$$\pi < x < \frac{3\pi}{2} \text{ (Quadrant III)}$$

GSEB Marking Scheme [4 Marks]

1. Determine range for $x/2$ ($\frac{\pi}{2} < x/2 < \frac{3\pi}{4}$) +1.0 Mark
2. Calculate $\sin(x/2)$ (+ sign in Q2) +1.0 Mark
3. Calculate $\cos(x/2)$ (- sign in Q2) +1.0 Mark
4. Calculate $\tan(x/2)$ ratio +1.0 Mark

Quadrant Diagnostic:

Divide range by 2: $\frac{\pi}{2} < \frac{x}{2} < \frac{3\pi}{4}$ (Quadrant II). In Quad II: $\sin(x/2) > 0$, $\cos(x/2) < 0$, $\tan(x/2) < 0$.

SMARTBOARD SOLUTION WORKSPACE
Step 1: Compute $\sin(x/2) = +\sqrt{\frac{1-\cos x}{2}}$

$$\sin\frac{x}{2} = +\sqrt{\frac{1 - (-1/3)}{2}} = \sqrt{\frac{4/3}{2}} = \sqrt{\frac{2}{3}} = \frac{\sqrt{6}}{3}$$

Step 2: Compute $\cos(x/2) = -\sqrt{\frac{1+\cos x}{2}}$ (Minus sign due to Quad II)

$$\cos\frac{x}{2} = -\sqrt{\frac{1 + (-1/3)}{2}} = -\sqrt{\frac{2/3}{2}} = -\frac{1}{\sqrt{3}} = -\frac{\sqrt{3}}{3}$$

Step 3: Compute $\tan(x/2) = \frac{\sin(x/2)}{\cos(x/2)}$

$$\tan\frac{x}{2} = \frac{\sqrt{6}/3}{-\sqrt{3}/3} = -\sqrt{2}$$

Final Values: $\sin\frac{x}{2} = \frac{\sqrt{6}}{3}, \cos\frac{x}{2} = -\frac{\sqrt{3}}{3}, \tan\frac{x}{2} = -\sqrt{2}$
Problem 10 • સ્વાધ્યાય 3 Q10

Given $\sin x = \frac{1}{4}$ in Quadrant II:

Find $\sin\frac{x}{2}, \cos\frac{x}{2}, \tan\frac{x}{2}$ where $\frac{\pi}{2} < x < \pi$.

$$\cos x = -\sqrt{1 - \sin^2 x} = -\sqrt{1 - 1/16} = -\frac{\sqrt{15}}{4}$$

GSEB Marking Scheme [4 Marks]

1. Calculate $\cos x = -\frac{\sqrt{15}}{4}$ (Quad II) +1.0 Mark
2. Determine range ($\frac{\pi}{4} < x/2 < \frac{\pi}{2}$) Quad I +1.0 Mark
3. Calculate $\sin(x/2)$ and $\cos(x/2)$ (both +) +1.0 Mark
4. Calculate $\tan(x/2)$ ratio +1.0 Mark

Range Check:

Since $\frac{\pi}{2} < x < \pi \implies \frac{\pi}{4} < \frac{x}{2} < \frac{\pi}{2}$ (Quadrant I). All values are POSITIVE!

SMARTBOARD SOLUTION WORKSPACE
Step 1: Calculate $\sin(x/2) = \sqrt{\frac{1-\cos x}{2}}$

$$\sin\frac{x}{2} = \sqrt{\frac{1 - (-\sqrt{15}/4)}{2}} = \sqrt{\frac{4 + \sqrt{15}}{8}} = \frac{\sqrt{5} + \sqrt{3}}{4}$$

Step 2: Calculate $\cos(x/2) = \sqrt{\frac{1+\cos x}{2}}$

$$\cos\frac{x}{2} = \sqrt{\frac{1 + (-\sqrt{15}/4)}{2}} = \sqrt{\frac{4 - \sqrt{15}}{8}} = \frac{\sqrt{5} - \sqrt{3}}{4}$$

Step 3: Calculate $\tan(x/2) = \frac{\sin(x/2)}{\cos(x/2)}$

$$\tan\frac{x}{2} = \frac{\sqrt{5}+\sqrt{3}}{\sqrt{5}-\sqrt{3}} = 4 + \sqrt{15}$$

Final Values: $\sin\frac{x}{2} = \frac{\sqrt{5}+\sqrt{3}}{4}, \cos\frac{x}{2} = \frac{\sqrt{5}-\sqrt{3}}{4}, \tan\frac{x}{2} = 4+\sqrt{15}$
